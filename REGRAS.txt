PASTAS:
a pasta SQL deve conter os arquivos .sql
a pasta DER deve conter os arquivos .mwb

Versionamento:
Arquivos não devem ser apagados. Quando uma mudança for feita, deve-se adicionar
um novo arquivo com a versão seguinte (versão atual +1)

Nomenclatura:
der-megustaVxx.mwb  xx=número da versão
megustaVxx.sql  xx=número da versão

Tabelas:
padrão snake case
primary key de tabela comum = id
primary key composta de tabela associativa = fk_tabela1, fk_tabela2
coluna de dinheiro DECIMAL(19,4)
comandos sql em CAPS LOCK
